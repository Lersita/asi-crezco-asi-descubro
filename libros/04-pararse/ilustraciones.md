# Libro 4 · Tomi aprende a pararse · Ilustraciones

Un prompt por página (las dobles llevan una sola imagen panorámica). Mismo método que el libro 3 (`ilustraciones/README.md`): Nano Banana Pro en 2K, pasando como referencia la hoja de personajes del libro 4 (`referencias/hoja-personajes-libro4.png`) y la doble 10 del libro 3 (`libro3/d10-v2.png`) para el estilo, el living y el sillón. Las dobles salen en 21:9 y se recortan a 2:1. Se generan con `herramientas/generar_libro.py 4`.

La versión mujer se hace editando cada imagen de Tomi con Nano Banana 2 y la hoja `referencias/hoja-personajes-emi-libro4.png` (`herramientas/emi_libro4.py`).

Cada prompt se arma así: **[ESTILO] + escena + [REGLAS]**.

**[ESTILO]**: archivo `ilustraciones/herramientas/style-libro4.txt`.

**[REGLAS]**
