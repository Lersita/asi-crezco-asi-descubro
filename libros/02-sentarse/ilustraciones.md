# Libro 2 · Tomi aprende a sentarse · Ilustraciones

Un prompt por página (las dobles llevan una sola imagen panorámica). Mismo método que el libro 1, explicado en `ilustraciones/README.md`: se generan con Nano Banana Pro en 2K, pasando como referencia la hoja de personajes del libro 2 y la portada del libro 1 (`p01-portada-v2.png`) para el estilo. Las dobles salen en 21:9 y se recortan a 2:1.

Cada prompt se arma así: **[ESTILO] + escena + [REGLAS]**.

**[ESTILO]** (archivo `ilustraciones/herramientas/style-libro2.txt`)
```
Premium children's picture book illustration in exactly the same handmade cut-paper collage style, palette, paper textures and lighting as the second reference image. The baby Tomi must look exactly like in the first reference image: a 7-month-old baby boy, chubby, short light chestnut-brown hair with one curl above the forehead, honey-colored eyes, light warm peach skin, pink cheeks, leaf-green short-sleeved bodysuit with a tiny colorful ball printed on the chest, barefoot. Rula is a large soft ball, about as big as the baby's whole torso, six vertical segments red, orange, yellow, leaf green, sky blue, violet. Full-bleed, no frame, no border, no panel, no dividing line. No text, no letters, no numbers.
```

**[REGLAS]**
```
The baby is always on the floor on the soft knitted blanket, with soft cushions around him, and an adult partially visible nearby. No small objects near the baby. Keep faces and the ball away from the vertical center line. Calm plain area in the upper part for text.
```
