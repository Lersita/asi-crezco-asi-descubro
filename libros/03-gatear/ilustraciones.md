# Libro 3 · Tomi aprende a gatear · Ilustraciones

Un prompt por página (las dobles llevan una sola imagen panorámica). Mismo método que los libros 1 y 2 (`ilustraciones/README.md`): Nano Banana Pro en 2K, pasando como referencia la hoja de personajes del libro 3 (`referencias/hoja-personajes-libro3.png`) y la portada del libro 2 (`libro2/p01-portada-v1.png`) para el estilo y el living. Las dobles salen en 21:9 y se recortan a 2:1.

La versión mujer se hace editando cada imagen de Tomi con Nano Banana 2 y la hoja `referencias/hoja-personajes-emi-libro3.png`.

Cada prompt se arma así: **[ESTILO] + escena + [REGLAS]**.

**[ESTILO]**: archivo `ilustraciones/herramientas/style-libro3.txt`.

**[REGLAS]**
```
An adult partially visible nearby. No small objects near the baby. Keep faces and the ball away from the vertical center line. Calm plain area in the upper part for text.
```

El "piso del pasillo" del texto es el piso de madera brillante, sin alfombra, que sigue hacia una puerta abierta. La "alfombra" es la alfombra tejida del living de los libros anteriores.
