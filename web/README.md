# Web de la colección (prototipo)

`index.html` es una página sola, sin dependencias: elegís nena o nene, escribís el nombre y se actualizan la tapa, el cuento y la colección. Las imágenes están en `img/` (versiones livianas de las ilustraciones y figuritas recortadas de las hojas de personajes).

El archivo no lleva `<!doctype>` ni `<head>` porque se publica como Artifact de Claude, que los agrega. Para subirlo a Vercel u otro hosting hay que envolverlo en un HTML completo.
